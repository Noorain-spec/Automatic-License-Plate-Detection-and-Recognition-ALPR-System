# Automatic License Plate Detection & Recognition (ALPR) System

An end-to-end traffic enforcement system that detects Indian vehicle license plates, reads the plate number via OCR, checks vehicle documents (RC, PUC, Insurance), detects helmet violations, and automatically sends challan emails to violators.

---

## Features

- **License plate detection** — two-stage pipeline: vehicle detection (YOLOv8n COCO) → plate detection (fine-tuned Indian plate model, mAP50 99.4%)
- **OCR** — multi-path EasyOCR with deskew, CLAHE, Otsu & adaptive thresholding; Indian plate format correction
- **Helmet violation detection** — YOLOv8 helmet/no-helmet classifier
- **Document violation check** — expired RC, PUC, Insurance flagged automatically
- **Challan email** — auto or manual email sent to registered vehicle owner on violation
- **Owner database** — SQLite DB with add / edit / delete via Streamlit UI

## Overall Data Flow

```
Input Image/Video
       ↓
  Vehicle Detection (COCO YOLOv8n)
       ↓
  License Plate Detection (fine-tuned YOLOv8n)
       ↓
  Plate Crop → Deskew → 3× Preprocessing
       ↓
  EasyOCR / PaddleOCR → Indian regex correction
       ↓
  DB Lookup (SQLite) → Check RC/PUC/Insurance expiry
       ↓
  [Optional] Gmail challan email → Owner
       +
  Helmet violation check (separate model) → Same email pipeline

```

## Setup

### Linux / macOS

```bash
# 1. Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# 2. Install dependencies
pip install -r req.txt

# 3. Run the app (from project root)
streamlit run app.py
```

### Windows

```bat
:: 1. Create and activate virtual environment
python -m venv venv
venv\Scripts\activate

:: 2. Install dependencies
pip install -r req.txt

:: 3. Run the app (from project root)
streamlit run app.py
```

> **Windows note:** If `cv2` or `torch` installation fails, ensure you have the [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) installed. For GPU support on Windows, install the CUDA-compatible torch version from [pytorch.org](https://pytorch.org/get-started/locally/) before running `pip install -r req.txt`.
